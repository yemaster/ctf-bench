# Reverse — 去符号的链式许可证

- **方向**：Reverse
- **难度**：难
- **分值**：160
- **预计时间**：40–60 分钟
- **知识点**：去符号 ELF、节表与 `.rodata`、结构体数据块、字节置换、相邻字节链、逆变换

## 背景

培训系统里有一个本地许可证检查器 `checker`。它要求输入固定长度的许可证 key，
检查通过后才会打印真正的 flag。源码没有随程序发布，而且二进制已经被去符号。

检查不是单一仿射变换，而是至少两层可逆校验：先对 key 做字节置换，再用相邻字节
链把结果与目标表比较。检查通过后，程序才用 key 派生的流解码 flag。

## 目标

找到正确的许可证 key，运行 `public/checker`，取得形如 `flag{...}` 的输出。
同时说明如何在不依赖源码和符号表的情况下从公开二进制中恢复所需数据。

## 学员材料

- `public/checker`：x86_64 Linux ELF 可执行文件（已 stripped）

## 运行方式

```bash
chmod +x public/checker
./public/checker
```

## 程序行为

1. 打印 `license key:`，读取一行输入；
2. 检查长度是否为固定值；
3. 第一层：按固定字节置换重排输入；
4. 第二层：把重排结果与前一字节、位置常量做链式异或，再与目标表比较；
5. 两层都通过后打印 `access granted`，并用 key 解码、打印 flag。

## 规则与边界

- 只分析本地附件，不涉及远程服务。
- 允许 `file`、`readelf`、`objdump`、`gdb`、Python 等工具。
- 不要修改系统配置；不需要 root 权限。
- 程序中的 key 不在二进制中明文出现，flag 也经过编码；`strings` 不会直接给出答案。

## 提示

1. `file public/checker` 会显示 stripped，`nm` 没有可用符号。改用
   `readelf -SW` 找 `.rodata`，再用 `objdump -d -M intel` 观察检查循环。
2. `.rodata` 中有一个带标记的许可证数据块，依次包含 magic、key 长度、flag 长度、
   置换表、目标表和编码后的 flag。先确认结构体布局，再按长度切片。
3. 第一层是 `p[i] = key[perm[i]]`；第二层类似
   `target[i] = p[i] ^ p[i-1] ^ f(i)`，其中 `p[-1]` 是固定种子，`f(i)` 只与位置有关。
4. 逆变换顺序与正向相反：先由目标表反推链式结果，再用置换的逆映射恢复 key。
   注意 8 位无符号回绕。
5. 恢复 key 后可以直接让未修改的 `checker` 解码 flag；不需要自己猜 flag。

## 交付

提交 flag，并给出：

- 如何从公开二进制定位许可证数据块；
- 两层校验的逆向公式；
- 恢复出的 key（或可复现的求解脚本）。
